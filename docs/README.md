## 先分清两个概念

- **本机画面**：你在显示器上直接看到的窗口。
- **捕获画面**：截图、录屏或会议软件收到的画面。

“透明所选”改变捕获亲和性，不是调节本机桌面窗口的不透明度。不同捕获后端会有不同表现，操作后应使用目标截图 / 录屏软件验证。
