# 常见问题 · AkashaVeil

[文档导航](README.md) · [使用指南](USER_GUIDE.md)

## 为什么点了保护，某个录屏软件仍能看到窗口？

显示亲和性由 Windows 和捕获端共同决定。桌面捕获、窗口捕获、会议共享、WGC、游戏捕获等路径不等价；部分后端或渲染方式不遵循该设置。先确认窗口权限、系统版本和实际后端，再用同一后端检查输出，不以状态栏成功替代实际画面。

## “透明所选”为什么是黑色？

这是捕获内容的保护状态，不是本机窗口的透明度滑块。`WDA_MONITOR` 在不同 Windows / 后端上可能产生空白或黑色；旧系统不具备较新系统的窗口捕获排除语义。

## 是否支持 Windows 7 和 ARM64？

提供 x86、x64、arm64 产物，并按系统能力分级。完整捕获排除需要 Windows 10 2004+，推荐 Windows 10 / 11。Windows 7 与 ARM64 本版缺少完整目标真机验证记录，不能把交叉编译当作实机通过。

## 为什么提示权限不足？

普通权限进程通常不能管理已提权目标。请在确需管理该目标时使用同等权限运行工具；受保护进程和特殊窗口仍可能拒绝操作。

## 关闭窗口为什么还在运行？如何真正退出？

默认关闭主窗口会收起到托盘。用设置菜单或托盘菜单的“退出”结束程序。需要清除目标的捕获亲和性时，退出前先“恢复所选”；退出本身不保证撤销全部历史亲和性设置。

## 单 EXE 为什么会生成 DLL / Worker 缓存？

发行时只需要一个 EXE，但跨进程操作会按目标架构释放内嵌辅助模块到 `%LOCALAPPDATA%/AkashaVeil/Runtime/`。缓存按模块内容标识复用，并在使用前校验；它们不是需要手动下载的第三方插件。

## 会注入目标软件或录屏软件吗？

跨进程设置显示亲和性使用架构匹配的短时辅助模块与 Windows 窗口线程钩子。仅捕获水印的画面合成和代理窗口是另一条路径，不修改或替换录屏软件本身。不要把“没有内核驱动”理解为“完全不使用跨进程机制”。

## 仅捕获水印应该在录屏软件中选哪个源？

路线 A 对应显示器 / 屏幕捕获；路线 B 对应工具创建的受控捕获源窗口。选择原始目标窗口不等同于 A 路线；B 窗口无法列出时改用 A。两者均属于需要按后端验证的实验性能力。

## 隐水印能从任何截图或视频里恢复吗？

不能。已验证本地图片和受控带标题栏窗口的真实桌面截图→GUI 提取链路；这不表示任意后端都支持。直接抓取原窗口可能漏掉外部水印叠层，请截取屏幕画面或指定代理输出。未检测到时核对密钥、保持原始像素尺寸并裁剪目标区域后重试。重采样、裁剪、旋转和压缩仍可能破坏水印。密钥或载荷不能单独证明身份和归属，本版没有完整追溯服务。

## 32 字节载荷等于 32 个汉字吗？

不等于。上限按 UTF-8 字节计算，常见汉字通常占 3 字节，其他字符可能不同。请看图片水印窗口中的实际字节计数。

## 密钥存在哪？为什么重开后为空？

隐水印密钥不保存到配置，只用于当前操作；重开后需要重新输入。请自行保存密钥。配置中的水印文字、载荷、本地编号和导出的文件可能包含私人内容，分享前应检查。

## 配置怎么备份？怎么便携运行？

默认备份 `%APPDATA%/AkashaVeil/profile.ini`。便携运行时，在 EXE 同目录放置 `portable.ini` 标记，实际配置为同目录 `AkashaVeil.ini`；也可以通过 `--profile <文件>` 指定位置。便携目录必须可写。

## 关于页 GitHub 按钮会自动联网吗？

不会自动打开。只有点击按钮时，系统默认浏览器才会访问显示的仓库地址。程序本身不做后台联网、遥测、上传或自动检查更新。

## 如何反馈问题？

在 [GitHub Issues](https://github.com/Henglie/AkashaVeil/issues) 提供版本、EXE 架构、Windows 版本、权限、目标程序与捕获后端、复现步骤、期望 / 实际结果。截图中遮盖私人路径、窗口标题、密钥和水印载荷。程序“关于 → 复制信息”可提供版本与架构摘要。
