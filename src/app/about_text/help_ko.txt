AkashaVeil 도움말(오프라인)

고급 설정은 캡처 내용, 가시 워터마크, 숨은 워터마크, 출력/미리 보기의 네 그룹입니다. 두 워터마크는 독립적으로 켜고 함께 사용할 수 있으며 표시 범위도 선택합니다. 이미지 기능은 자동 정렬 추출 페이지로 열리고 고급 매개 변수는 접혀 있습니다. 제어된 테두리 창의 실제 바탕 화면 캡처부터 GUI 추출까지 검증했습니다. 원래 창을 직접 캡처하면 외부 레이어가 빠질 수 있습니다.

1. 빠른 시작
1. 왼쪽에는 창 또는 프로세스 목록이 표시됩니다. 탭으로 보기를 전환하고 필터 상자로 제목, 프로세스 이름 또는 경로를 일치시킵니다.
2. 하나 이상의 행을 선택한 다음 '선택 항목 보호' 또는 '선택 항목 투명화'를 사용합니다. '선택 항목 복원'은 이 도구가 설정한 표시 선호도를 되돌립니다.
3. '모두 보호'와 '모두 복원'은 현재 필터링된 결과의 모든 행에 적용됩니다. 목록 아래 요약에는 행, 선택된 행, 대상 창 수가 표시됩니다.
4. 열 머리글을 클릭하여 정렬합니다. 목록은 Ctrl/Shift 다중 선택, Ctrl+A, 선택 지우기를 지원합니다.
5. 단축키: Ctrl+H 보호, Ctrl+U 복원, 목록에 포커스가 있을 때 Ctrl+A 모두 선택, Ctrl+S 프로필 저장, Ctrl+O 프로필 불러오기, Ctrl+E 목록 내보내기, Ctrl+P 환경 설정, Ctrl+W 고급 모드, Ctrl+F 필터로 포커스, Ctrl+R 또는 F5 새로 고침, Esc 필터 지우기, F1 이 도움말 열기. Tab/Shift+Tab으로 컨트롤 간 포커스를 이동합니다.

2. 보호 모드
- 보호는 지원되는 캡처 경로에서 창을 생략하도록 시스템에 요청합니다. Windows 10 2004 이상은 WDA_EXCLUDEFROMCAPTURE를 제공합니다. Windows 7의 WDA_MONITOR는 의미가 다릅니다. UI에는 요청 값뿐 아니라 시스템에서 다시 읽은 값이 표시됩니다.
- 투명화는 창 내용을 투명하게 하도록 시스템에 요청합니다. 결과는 Windows 버전, 창 렌더러, 캡처 백엔드에 따라 달라집니다.
- 복원은 이 도구가 변경한 표시 선호도만 되돌립니다. 보호 중 대상이 변경한 무관한 상태는 덮어쓰지 않습니다. 대상이 사라지거나 ID가 재사용되면 작업을 중지합니다.
- 관리자 권한: 권한이 상승된 프로세스의 창을 보호하려면 일반적으로 이 도구를 관리자로 실행해야 합니다. 실패는 보고되며 보호됨으로 표시되지 않습니다.

3. 고급 모드
1. 창을 선택하고 '고급 모드'를 엽니다. 캡처 내용, 워터마크 스타일, 표시 범위, 텍스트, 색, 글꼴 크기, 간격, 불투명도를 설정합니다. 적용 전에 미리 보기를 사용합니다.
2. 캡처 내용:
   - 원본 내용(워터마크만): 로컬 화면과 캡처 프레임은 원본 내용을 유지하며 선택한 표시 범위에 따라 워터마크가 그려집니다.
   - 단색 대체／텍스트 자리표시자: 원본을 제외하고 대상 뒤에 대체 항목을 표시합니다. 이는 실험적인 데스크톱 합성 경로이며 Windows 10 2004 이상, DWM, 불투명한 최상위 창이 필요합니다.
3. 워터마크 스타일: 끔, 대각선 타일, 가운데, 오른쪽 아래.
4. 표시 범위:
   - 화면 및 캡처: 로컬과 지원되는 백엔드의 캡처에서 표시됩니다.
   - 캡처 전용(내용 대체): 현재 구현은 원본 내용을 제외하고 대체 또는 워터마크를 표시합니다. 원본 캡처 이미지에 보이지 않게 텍스트를 추가하지 않으며 원본 동적 내용을 유지하지 않습니다. 캡처에 원본을 남겨야 하면 '원본 내용(워터마크만)'을 선택하세요.
5. 필드: {title}, {process}, {pid}, {time}, {id}(사용자가 입력하는 로컬 추적 ID). ID는 로컬에만 남으며 지문은 수집되지 않습니다.
6. 프리셋: 기밀, 내부용, 추적, 사용자 지정. 미리 보기와 캡처 미리 보기로 결과를 확인할 수 있습니다. 취소하면 아무것도 적용되지 않습니다.
7. 레이어를 사용하려면 이 애플리케이션이 실행 중이어야 합니다. 복원하면 선택한 창의 모든 레이어가 제거됩니다. 종료하면 레이어는 제거되지만 기존 캡처 제외는 유지됩니다. 다시 연 후 복원하세요.
8. 알려진 제한: 레이어는 이동, 크기 조정, 최소화, 숨기기, 일반적인 가림을 처리합니다. 전체 화면, 투명/특수 창, 다중 모니터/혼합 DPI, 창 캡처, OBS, 회의 공유는 백엔드별로 검증해야 합니다. 데스크톱 BitBlt 결과가 다른 백엔드를 증명하지는 않습니다.

숨은 워터마크와 로컬 이미지
- R-DCT, DCT, DWT를 선택할 수 있습니다. R-DCT는 키 기반 분산 파일럿, 바이트별 공간 인터리빙, 소프트 판정과 RS 오류/소거 정정을 사용합니다. 삽입에는 256x256 픽셀 이상이 필요하며 페이로드는 최대 32 UTF-8 바이트, 키는 1~128 바이트로 저장되지 않습니다.
- R-DCT 기본값 24는 데이터/파일럿 간격 64/48에 해당하며 미세한 무늬가 생길 수 있습니다. 자른 이미지는 타일/위상 검색을 켜고, 크기를 바꾼 이미지는 원래 너비/높이와 1이 아닌 배율을 지정하세요. 동기 점수는 0~1000, 기존 방식은 0~32입니다. 배율/원근 자동 추정, 화면 촬영, 인쇄/스캔, 임의 회전 복원은 보장하지 않습니다.

4. 프로필 및 레이아웃
- '선택 항목 기억'은 경로, 클래스, 제목, 모드, 효과를 규칙으로 저장합니다. 나중에 규칙을 적용하면 해당 조건과 일치합니다.
- '보호 적용'은 현재 규칙을 적용합니다. 여러 항목이 일치하면 무작위로 하나를 고르지 않고 모호함으로 보고합니다.
- '레이아웃 복원'은 저장된 위치 및 크기/표시 상태만 적용합니다. 저장/불러오기는 프로필을 읽고 씁니다. 목록 내보내기는 현재 필터링된 행의 CSV 메타데이터를 씁니다.
- 프로필은 schema 4를 사용하며 schema 1/2/3을 읽을 수 있습니다. 이전 프로필은 워터마크를 자동으로 활성화하지 않으며 schema 1은 백그라운드 보호나 닫으면 트레이로 최소화를 자동으로 활성화하지 않습니다.
- 기본 프로필은 %APPDATA%\AkashaVeil\profile.ini입니다. 프로그램 옆에 portable.ini가 있으면 해당 파일을 사용합니다. --profile <file>은 명시적 경로를 선택합니다.

5. 환경 설정
- 자동 새로 고침: 선택한 간격(100~60000ms)으로 새로 고칩니다. 자동 작업이 없으면 백그라운드 폴링이 실행되지 않습니다.
- 자동 보호: 새 창을 저장된 규칙과 프로그램 목록에 일치시킵니다. 알림, 시작 시 기존 창 처리, 준비 완료 재시도 한도(0~60000ms)를 설정할 수 있습니다.
- 트레이: 트레이 아이콘 표시, 닫으면 트레이로 최소화, 이 앱의 작업 표시줄 버튼 숨기기(트레이 필요). 명시적 '종료'만 프로세스를 끝냅니다.
- 무작위화: 이 창의 제목, 트레이 아이콘 또는 트레이 도구 설명을 무작위화하고 설정을 유지합니다.
- 적용/취소/초기화: 적용은 변경 사항을 즉시 쓰고 활성화합니다. 취소는 이미 적용된 변경을 유지합니다. 초기화는 확인 후 저장된 규칙, 프로그램 목록, 환경 설정을 지웁니다.

6. 개인정보 및 로컬 데이터
- 애플리케이션은 네트워크에 연결하지 않고 데이터를 업로드하지 않으며 텔레메트리나 장치 지문을 수집하지 않습니다.
- 창/프로세스 메타데이터와 환경 설정은 로컬 관리에만 사용됩니다. 추적 ID는 로컬 프로필 또는 사용자가 명시적으로 내보낸 파일에만 기록됩니다.
- 캡처 미리 보기, CSV 파일, 프로필은 사용자가 로컬에서 선택한 경로를 사용합니다. 자동으로 업로드되는 것은 없습니다.

7. 문제 해결
- 실패/오류 행은 해당 창에 대한 실제 작업이 실패했음을 의미합니다. 권한, 대상이 아직 존재하는지, 시스템이 선택한 모드를 지원하는지 확인하세요.
- 제외/투명화가 효과가 없으면 먼저 백엔드를 확인하세요. 스크린샷 및 녹화 도구마다 캡처 경로가 다르며 표시 선호도를 따르지 않는 도구도 있습니다.
- 대체 또는 캡처 전용이 실패하면 Windows 버전, 대상이 불투명한 최상위 창인지, 이 도구가 실행 중인지 확인하세요.
- 프로필이 손상되면 애플리케이션은 현재의 유효한 프로필을 교체하지 않습니다. 읽기 전용 포터블 디렉터리에는 쓰기 가능한 '다른 이름으로 저장' 위치가 필요합니다.
- 정보 창의 라이선스, 타사, 도움말 탭은 오프라인으로 작동합니다. 정보 복사는 피드백용으로 버전, 아키텍처, 라이선스, 개인정보 요약을 복사합니다.

8. 정보
버전과 아키텍처는 빌드의 단일 소스(CMake 프로젝트 VERSION 및 대상 아키텍처)에서 가져옵니다. 라이선스는 Apache-2.0이며 전체 텍스트는 라이선스 탭에 있습니다. 후원은 자발적이며 어떤 기능에도 영향을 주지 않습니다. 이미지는 이 사용자 빌드에만 포함되며 공개 소스에는 개인 경로나 연락처 정보가 포함되지 않습니다.
