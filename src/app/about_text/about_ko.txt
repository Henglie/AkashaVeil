AkashaVeil은 로컬에서 실행되는 Windows 창 캡처 관리 도구입니다.

기능
- 창과 프로세스를 열거한 뒤 선택한 창을 보호하거나 투명화하고 나중에 복원합니다.
- 가시 워터마크: 대각선 타일, 가운데, 오른쪽 아래. 텍스트, 색, 글꼴 크기, 간격, 불투명도를 조정할 수 있으며 프리셋과 {title} {process} {pid} {time} {id} 필드를 지원합니다.
- 대체 및 캡처 전용 모드: 단색 또는 텍스트 자리표시자 대체와 캡처 전용 워터마크. 이는 실험적인 데스크톱 합성 경로이며 Windows 10 2004 이상과 불투명한 최상위 창이 필요합니다.
- 프로필: 창 규칙, 프로그램 목록, 레이아웃, 상태를 저장/불러옵니다. 창 기억, 저장된 규칙 적용, CSV 메타데이터 내보내기를 지원합니다.
- 환경 설정: 자동 새로 고침, 자동 보호, 트레이, 닫으면 트레이로 최소화, 제목/아이콘/도구 설명 무작위화, 시작 시 기존 창 처리, 준비 완료 재시도 한도.
- 언어: 중국어(간체), 영어, 스페인어, 프랑스어, 러시아어, 아랍어, 터키어, 일본어, 한국어를 선택할 수 있습니다. 번역이 없으면 영어로 대체되며, 중국어(번체) 시스템은 기본적으로 영어를 사용합니다.

개인정보 및 로컬 처리
모든 처리는 이 컴퓨터에서만 이루어집니다. 애플리케이션은 네트워크에 연결하지 않고 데이터를 업로드하지 않으며 텔레메트리나 장치 지문을 수집하지 않습니다. 사용자가 입력한 추적 ID는 로컬 프로필 또는 사용자가 내보낸 파일에만 남습니다.

제한
보호 효과는 Windows 버전, 대상 창의 렌더링 방식, 실제 캡처 백엔드에 따라 달라집니다. 데스크톱 BitBlt, 시스템 스크린샷, Desktop Duplication, 창 캡처, OBS, 회의 공유는 각각 검증해야 합니다. 한 백엔드의 결과를 다른 백엔드에 일반화할 수 없습니다. Windows 7은 WDA_EXCLUDEFROMCAPTURE를 제공하지 않으므로 일부 모드는 최신 시스템에서만 작동합니다.
