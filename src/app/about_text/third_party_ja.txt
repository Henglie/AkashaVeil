サードパーティ コンポーネントとライセンス

1. 同梱のサードパーティ オープンソース コンポーネント
このバージョンは、サードパーティのオープンソース ライブラリ、フォント、画像アセットを同梱またはリンクしていません。プログラム コード、ヘルプ テキスト、ブランド アイコンは、このプロジェクトが作成または生成したものです。

2. Windows システム コンポーネント
プログラムは User32、GDI32、GDI+、Shell32、Advapi32、Dwmapi、Comctl32、Comdlg32、UxTheme、Shlwapi などの Windows システム DLL を呼び出します。これらは Windows オペレーティング システムの一部であり、このプログラムと共に再配布されず、Microsoft ソフトウェア ライセンスの下で使用されます。

3. ビルド ツールとランタイム
プログラムは Microsoft Visual C++ ツールチェーンでビルドされています。C/C++ ランタイムは EXE に静的にリンクされているため、別個のランタイム ファイルは配布されません。コンパイラとランタイムの再配布条件は Microsoft ライセンスに従います。

4. 変更と配布の義務
このプロジェクト自体のコードは Apache-2.0 で公開されています。変更したファイルを配布する場合は、著作権とライセンス表示を保持し、変更内容を明記する必要があります。このバージョンには NOTICE ファイルはなく、Apache-2.0 は未変更のバイナリに追加の NOTICE を要求しません。将来のサードパーティ コードやアセットは、固定バージョンとソース、記録されたライセンスと変更、法的に必要な帰属表示をこのページと公開ソースに保持する必要があります。公開時のクリーンアップで帰属表示を削除してはなりません。

5. アイコン
アプリケーション アイコンは製品所有者が承認したブランド アイコンで、EXE、ウィンドウ、トレイに統合されています。支援画像はこのユーザー ビルドにのみ私有入力として埋め込まれ、公開ソースにはパス、QR コード、連絡先情報のリテラルは含まれません。
