凌空罩帮助（离线，0.1.0）

一、快速开始
1. 启动后主窗口左侧是窗口/进程列表，顶部页签切换“窗口”和“进程”，筛选框按标题、进程名或路径过滤。
2. 选中一行或多行，使用右侧“保护所选”或“透明所选”；“恢复所选”撤销本工具设置的显示亲和性。
3. “全部保护/全部恢复”作用于当前筛选结果的全部行。列表底部摘要显示行数、已选数和目标窗口数。
4. 点击列标题排序；列表支持 Ctrl/Shift 多选、Ctrl+A 全选和清空选择。
5. 快捷键：Ctrl+H 保护所选；Ctrl+U 恢复所选；Ctrl+A 在列表中全选；Ctrl+S 保存配置；Ctrl+O 加载配置；Ctrl+E 导出清单；Ctrl+P 偏好设置；Ctrl+W 高级模式；Ctrl+F 聚焦筛选框；Ctrl+R 或 F5 刷新；Esc 在筛选框中清空；F1 打开帮助。Tab/Shift+Tab 在控件间移动焦点。
6. 语言：设置菜单可选简体中文、英语、西班牙语、法语、俄语、阿拉伯语、土耳其语、日语、韩语；缺译回退英语。阿拉伯语界面为从右到左布局。

二、保护模式
- 保护：请求系统在支持的捕获路径中排除该窗口。Windows 10 2004 及以上提供 WDA_EXCLUDEFROMCAPTURE；Windows 7 的 WDA_MONITOR 语义不同。界面显示从系统读回的实际状态，不是单纯请求值。
- 透明：请求系统将窗口内容显示为透明。实际效果受 Windows 版本、窗口渲染器和捕获后端影响。
- 恢复：只恢复本工具修改的显示亲和性；目标窗口在保护期间自行改变的无关状态不会被覆盖。目标消失或标识被复用时不继续操作。
- 管理员权限：保护管理员权限进程的窗口通常需要以管理员身份运行本工具；普通权限下失败会显示错误，不把失败行标成成功。
- 失败行表示该窗口的实际操作失败。查看状态栏和错误文本，确认权限、目标是否仍存在、系统是否支持所选模式；重试只作用于失败对象。

三、高级模式
1. 选中窗口后点击“高级模式…”。对话框可设置捕获内容、水印形式、显示范围、文字、颜色、字号、间隔、不透明度和隐水印，并提供预览。
2. 捕获内容：
   - 原始内容（仅叠加水印）：本地画面与捕获画面保留原始内容，水印按所选显示范围叠加。
   - 从捕获中排除／透明：请求系统排除或使原内容透明。
   - 纯色替身／文字占位替身：排除原内容后在目标后方显示替身。属于实验性桌面合成路径，需要 Windows 10 2004+、DWM 与不透明顶层窗口。
3. 水印形式：关闭、斜向平铺、居中、右下角标。
4. 显示范围：
   - 屏幕与捕获均可见：在本地屏幕与支持的后端捕获中可见。
   - 仅捕获可见（替换原内容）：用于替身或排除路线；它不在原始捕获图像上隐形加字。需要保留捕获中的原始动态内容时，请选“原始内容（仅叠加水印）”并设置仅捕获。
5. 字段：{title} 窗口标题、{process} 进程名、{pid} 进程 ID、{time} 当前时间、{id} 用户自行填写的本地追踪编号。编号仅本地使用，不采集指纹。
6. 预设：保密、内部使用、追踪编号、自定义。预览与“捕获预览”用于应用前检查；取消不应用。
7. 图层需要本工具保持运行。恢复操作移除所选窗口的全部图层；退出程序会移除图层但保留已有的捕获排除，重新打开后可再次恢复。
8. 已知边界：图层对移动、缩放、最小化、隐藏和普通遮挡有处理；全屏、透明/特殊窗口、跨屏/混合 DPI、窗口捕获、OBS、会议共享需按后端分别验证，不能以桌面 BitBlt 的结果代替。

四、仅捕获保留原内容
- 该模式让本地屏幕保持清洁，同时让支持的捕获路径得到原始动态内容加显性/隐性水印。它不注入目标进程，也不注入 OBS/会议进程。
- A 路线（显示器捕获）：从显示器捕获原内容并叠加水印；在 OBS/会议中选择“显示器采集”有效，选择“窗口采集→原目标窗口”不会得到该效果。
- B 路线（捕获源代理）：程序创建离屏/遮挡的受控捕获源窗口 P，用 WGC 抓取目标原内容并合成水印；用户需在 OBS/会议中把捕获源选为 P。若捕获端无法列出 P，则回退 A 或报告失败。
- 当前已验证范围：离屏/自建窗口的 A/B 路线、原内容保留、本地清洁和恢复；真实显示器、OBS/会议实际选中、跨屏/混合 DPI、全屏、透明窗口和特殊渲染器仍需按环境验证。
- 使用前先确认目标窗口为不透明顶层窗口，并保持本工具运行；窗口关闭、最小化或身份失效时会停止会话并清理图层。

五、隐水印与本地图片水印
- 隐水印在显性水印之后写入，使用像素域盲水印，不需要联网追溯服务。当前提供两套算法：DCT（QIM）和 DWT（Haar LH3）。
- 载荷最多 32 个 UTF-8 字节；密钥 1–128 字节，仅用于本次会话，不会保存到配置。提取不需要原图，但需要同一密钥和协议参数。
- 显隐可以叠加：同一张最终图可以同时看到显性水印并提取隐性载荷。文件 PNG/BMP/JPEG 往返与内部鲁棒性矩阵已通过；实际外部捕获帧的隐水印提取尚未达标，当前版本不要依赖从 OBS/会议/系统截图提取隐水印。
- “设置 → 图片水印…”可对本地 PNG/JPEG/BMP 写入或提取；默认不覆盖源文件，覆盖前需要确认；可复制或导出提取到的载荷。文件不会上传，载荷写入像素而不是文件元数据。
- 几何、量化步长、JPEG 质量、搜索瓦片/相位等参数用于缩放、裁剪或未知来源图片；不确定时保持默认值。

六、规则、配置与布局
- “记住所选”把当前窗口的路径、类名、标题、模式和效果保存为规则；再次匹配时按规则应用。
- “设置 → 窗口规则…”可新增、编辑、删除、启用/停用规则，设置精确路径/类/标题、模式、替身、显性水印、显示范围、任务栏意图和几何。匹配到多个窗口时会报告歧义，不随机套用。
- “应用保护”对当前规则执行保护；“恢复布局”只应用已保存的几何/显示状态。
- “保存…/加载…”读写配置文件；“导出清单…”输出当前筛选行的 CSV 元信息。
- 当前配置 schema 4，可读 schema 1/2/3。旧配置不会自动加水印；schema 1 不自动启用后台保护/托盘收起。配置损坏时应用拒绝替换当前有效配置。
- 默认配置在 %APPDATA%\AkashaVeil\profile.ini；程序目录存在 portable.ini 时使用同目录配置；也可用 --profile <文件> 指定路径。便携只读目录需要可写的另存位置。

七、偏好设置、托盘与任务栏
- 自动刷新：按设定间隔刷新，范围 100–60000 毫秒；无自动任务时不后台轮询。
- 自动保护：匹配已存规则和程序名单的新窗口；可配置通知、是否处理启动时既有窗口，以及窗口就绪重试上限（0–60000 毫秒）。
- 托盘：显示托盘图标、关闭窗口时收起、隐藏本工具任务栏按钮（需要托盘）。显式“退出”才结束进程。
- 随机化：随机化本工具窗口标题、托盘图标或托盘提示，并保存设置。
- 目标任务栏：在“设置”菜单对所选窗口执行“隐藏目标任务栏按钮”或“恢复目标任务栏按钮”；本工具只恢复自己修改的样式位，不覆盖无关位。
- 应用/取消/重置：应用会立即写入并生效；取消保留此前已应用的更改；重置清空已存规则、程序名单和偏好，需确认。

八、命令行
用法：
  AkashaVeil list [--json]
  AkashaVeil protect|restore --process <PID> [--json]
  AkashaVeil protect|restore --window <HWND> [--json]
  AkashaVeil hide|unhide（protect|restore 的别名）
  AkashaVeil --version [--json]
  AkashaVeil [--profile <文件>]
  AkashaVeil --help

命令：
  list, windows      枚举顶层窗口
  protect, hide      对目标排除捕获或设为透明
  restore, unhide    恢复目标捕获

选项：
  --process, --pid   正的十进制进程 ID
  --window, --hwnd   非零十六进制窗口句柄；0x 前缀可选
  --json             输出便于程序解析的 JSON；不打开界面
  --profile <文件>   仅用于命令行输出语言的配置；不打开界面
  -h, --help, help   显示帮助并退出
  --version          显示版本并退出

退出码：0 全部成功，2 语法错误，3 无目标，4 部分失败，5 全部失败，6 超时/取消。
示例：
  AkashaVeil list --json
  AkashaVeil protect --process 1234
  AkashaVeil restore --window 0x00123456
  AkashaVeil --profile .\profile.ini protect --pid 1234

九、隐私与本地数据
- 应用运行时不联网、不上传、无遥测，不采集设备指纹。
- 窗口/进程元信息与偏好仅用于本地管理；追踪编号、载荷和密钥只写入本地配置、内存或用户主动导出的文件。
- 捕获预览、CSV 和配置均由用户在本机选择路径；程序不自动上传。

十、故障排查与兼容边界
- 保护/透明无效时，先确认捕获后端：不同截图/录屏软件使用不同捕获路径，某些路径不遵守显示亲和性。
- 替身、仅捕获或 B 路线失败时，确认 Windows 版本（需要 10 2004+ 的桌面合成能力）、目标是否为不透明顶层窗口，以及本工具是否仍在运行。
- 隐水印提取失败时，确认使用了写入时的同一算法、密钥和几何参数；实际外部捕获提取当前未达标，见第五节。
- 目标任务栏按钮异常时，使用“恢复目标任务栏按钮”；程序退出时会尝试恢复本会话修改的样式位。
- 配置损坏或便携目录只读时，应用拒绝替换当前有效配置；请选择可写的另存位置。
- Windows 7 仅支持分级能力；WDA_EXCLUDEFROMCAPTURE、WGC、部分桌面合成路径不可用。OBS/会议、系统截图、Desktop Duplication、窗口捕获等后端必须在目标环境分别验证。

十一、关于、许可与帮助
- “设置 → 关于”打开离线关于窗口，包含“关于”“许可”“第三方”“帮助”四个页签；F1 直接打开帮助页签。
- 许可为 Apache-2.0，完整文本在“许可”页签。投喂完全自愿，不影响任何功能；图片只在本用户构建中内嵌，公开源码不包含私人路径或联系方式。
- “复制信息”复制版本、架构、许可与隐私摘要，便于反馈；不会复制密钥或用户载荷。
